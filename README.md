# go4devops

A minimal Go "Hello World" program, used for testing/learning Go in a DevOps context (as the repo description says: "testing golang").

## What it does

`hello.go` defines a `main` package with a single `main()` function that prints `Hello Bava Go4DevOps` to stdout. There is no other logic.

## Tech stack

- Go

## Setup / running

```bash
go run hello.go
```

## Project structure

```
go4devops/
└── hello.go   # single-file "Hello World" program
```
